## TSD S-0001.04 — Exercise & anatomy library (PRD §S-0001.04)
| Aspect | Spec |
|--------|------|
| Interfaces | A search-and-filter function: input = free-text search (matched against exercise name and its muscle/equipment attributes), an anatomy group (chest, back, legs, shoulders, arms, core, full-body, or "all"), a difficulty (beginner, intermediate, advanced, or "all"), an equipment type (barbell, dumbbell, cable, bodyweight, or "all"), and a mechanics type (compound, isolation, or "any"); output = the list of exercises matching every active filter, each carrying name, target muscle, difficulty, equipment, mechanics type, an ordered list of execution cues, and a demonstration-video reference. A UI surface exposes: the search box; an anatomy-group selector; difficulty/equipment/mechanics filters; a reset action; a live result count; the filtered exercise cards (each with its video reference and an "add to routine" action); an anatomy inspector that visually highlights the selected anatomy group and toggles between anterior/posterior views; and a technique modal (per exercise) that opens a YouTube search for that exercise's technique tutorial and can be closed. |
| Data / State | Static, bundled exercise reference data (name, target muscle, difficulty, equipment, mechanics, cues, video reference) — the same shared exercise table S-0001.02's routine plan draws its per-exercise video from, extended with the difficulty/equipment/mechanics/cues fields; one reference table, not two. No persisted or server-side state; all filter selections, the anatomy-inspector view, and the technique modal's open state are transient/in-memory. "Add to routine" is a lightweight, session-only acknowledgment (e.g. a running pick list) — it does not feed into or alter S-0001.02's deterministic weekly-plan generation, which stays a pure function of goal/experience/cadence/hardware only. |
| Behavior | Any combination of search text, anatomy group, difficulty, equipment, and mechanics filters narrows the list to exactly the exercises matching every active filter (filters AND together; an unset filter — "all"/"any" — excludes that criterion from narrowing). The visible result count always equals the number of rendered exercise cards. When no exercise matches the active filters, the cards are hidden and a no-results state is shown instead, with a reset action that clears every filter to its default and restores the full list. Selecting a different anatomy group updates both the filtered list and the anatomy inspector's highlighted region; toggling anterior/posterior changes which body view is shown without changing the selected anatomy group or the filtered list. Opening an exercise's technique modal shows its name and cues plus a link that opens a YouTube search for that exercise's technique tutorial; the modal closes via its close control or a click outside it. |
| Access | Any visitor of the Exercise Library view; no auth. |
| Boundaries | YouTube — two independent, non-API uses: (1) each exercise card's demonstration reference (a stored per-exercise video reference, playable in place — same mechanism as before), and (2) the technique modal's "Watch on YouTube" action, which opens a constructed YouTube *search* URL built from the exercise's name (no curated video required for this action). No other network dependency. |
| Tests | unit: the filtering function, for representative filter combinations (search+anatomy, anatomy+difficulty, equipment+mechanics, and combinations with no match), returns only exercises matching every active filter (or an empty list when none match); every returned exercise has a well-formed video reference and a non-empty cues list. integration: typing in search and picking anatomy/difficulty/equipment/mechanics filters narrows the displayed cards and updates the visible count to match; the reset action restores the full list; a no-match combination shows the no-results state instead of cards; selecting an anatomy group updates the anatomy inspector's highlighted region; toggling anterior/posterior changes the displayed view; opening a card's technique modal shows its name/cues and a YouTube-search link, and closes on request. |
